# C++ Lab V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a polished, deployable C++ learning site with a portfolio homepage and a separate interactive practice workspace.

**Architecture:** Next.js App Router renders static learning content and focused client workspaces. A server route evaluates single-file C++17 through Judge0, while typed content files and browser persistence keep the first release usable before Supabase credentials are added.

**Tech Stack:** Next.js, TypeScript, Tailwind CSS, CodeMirror 6, Judge0 Cloud, Vitest, Testing Library, Playwright.

**Spec:** The approved plan in the current thread and the user-supplied concept image `C:\Users\user\Downloads\C++ Lab 程式學習工作台.png`, with the approved change that the homepage and practice workspace are separate routes.

## Global Constraints

- Traditional Chinese UI, desktop-first, accessible at narrower widths.
- Warm white page background, white content surfaces, deep ink typography, teal accent, and a dark C++ editor.
- Route `/` is the homepage only; route `/practice` is the full practice workspace.
- C++17, 64 KiB source limit, 10-second compile limit, 2-second execution limit, 128 MiB memory limit.
- Never execute untrusted code on the Next.js host; all execution goes through the server-side Judge0 adapter.
- No secrets in client bundles or Git.
